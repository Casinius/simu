# FP-PXPBD:修 bug + CRTP 收尾 + 测试基础设施

## 已发现的问题(本轮要修的)

**Bug 1 — `strain_to_cauchy` 非对称写入**(fpxpbd.h:429-436):offdiag 分量只写了 `C(r,c)`,镜像 `C(c,r)` 保持 0。下游 `C.inverse()`/`C.determinant()` 全部被污染,导致当前解析梯度/Hessian 错误(行为退化得和 FD 版不同)。

**Bug 2 — offdiag 链式缩放因子缺失**(MaterialBase):`energy_derivatives/energy_hessian` 返回的是"对称张量逐分量"约定;但求解器坐标约定是 offdiag 单坐标同时变 C(kl) 和 C(lk),真值差 ×2(梯度 offdiag)/ ×2×2(Hessian 含 offdiag 的行列)。推导结论:把 scale(对角=1,offdiag=2)折叠进 MaterialBase 后,`elastic_derivs` 现有的统一 ×2/×4 链式缩放恰好完全正确,无需再改。当前状态下 offdiag 步长系统性偏大,靠线搜索掩盖。

## 修改清单

### src/fpxpbd.h
1. `strain_to_cauchy`:offdiag 同时写 `(r,c)` 和 `(c,r)`。
2. `energy_derivatives`:offdiag 分量 ×2;注释改为"独立对称分量约定"。
3. `energy_hessian`:entry × `scale(r1,c1)·scale(r2,c2)`;修正过时注释(现存 (J/8)·tr(...) 与实现不符)。
4. CRTP 收尾:MaterialBase 加 `static constexpr bool needs_inversion_fix = false`,LogNeoHookean 覆写为 true;`process_unit` 中 `std::is_same_v<Material, LogNeoHookean>` 改为 `Material::needs_inversion_fix`。NeoHookeanMaterial concept 补 `psi` 检查。
5. `eval_f`:grad/hess 分支重复计算 `strain_jacobian(pt,...)`,提取为一次计算共用。
